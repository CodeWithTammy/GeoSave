# GeoSave

GeoSave is a mobile application that enhances the in-store shopping experience by delivering personalized deals when users enter a store's geofence. The app pulls relevant store information, including deals and store details, from Firebase Firestore, displaying them in a user-friendly RecyclerView on the homepage.

## Features

- **Geofencing Technology**: Receive notifications and personalized deal cards when entering a store's geofence.
- **Firebase Integration**: Fetch store-specific data such as store name, profile picture, type of store, and deal information from Firebase Firestore.
- **Deal History**: Store and view deal history for each store visited.
- **Profile Pictures**: Display store profile pictures dynamically.
- **Admin Functionality**: Admins can manage their store's profile, including login functionality with block status management.
- **Onboarding Screen**: Easy-to-follow onboarding experience for new users.
